## 一、项目概览

**ResearchMate** 是面向科研人员的**本地化 AI 学术助手**：文献库管理、语义检索、智能阅读、写作辅助、对话问答、Agent 工作流与科研 Skill 集成。**单机单用户、数据完全本地存储、轻量化**，无云端、无服务器依赖。

产品定位一句话：**"面向科研小白的 AI 科研伙伴：有需求就说话，系统自动选对工具、走对流程。"**

三层产品结构：
```
第一层：统一对话入口（顶层 Agent）——用户说一句话，系统判断怎么做
第二层：执行路径——随手答 / 科研 Skill / 专用 Agent / 工作流模板
第三层：能力底座——文献库(6维向量) / 写作项目 / 实验 / 数据
```

## 二、技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Python 3.11+ / FastAPI / SQLAlchemy / Pydantic v2 / uvicorn |
| 数据库 | SQLite 单文件（轻量默认）· 兼容 PostgreSQL（可选） |
| 向量 | 内存余弦计算（JSON 列存 embedding，无 pgvector 依赖）；可配 text-embedding 接口 |
| LLM | LiteLLM 兼容层：OpenAI 兼容 / Ollama / 离线 Mock（熔断降级） |
| 前端 | React 18 + TypeScript + Vite 5 + Ant Design 5 + React Router + React Flow（图谱） |
| PDF | pdf.js（前端渲染）+ 本地解析（后端文本抽取，无 GROBID） |
| 打包 | PyInstaller（Windows 绿色包）+ 前端 dist 单端口托管 |

## 六、核心流程

### 6.1 PDF 处理流水线（papers → paper_service）
上传 → 后台任务 → 文本抽取 → 拆 6 维（背景/方法/结果/结论/标题关键词/创新点）→ 分块 + embedding → status=ready → 全文摘要。

### 6.2 语义检索（search_service）
6 维向量内存余弦 + 关键词降级；无 Embedding Key 自动降级关键词检索。

### 6.3 顶层 Agent（app/agent）
对话 → `top_agent` 路由 → 随手答 / 科研 Skill（337 内置）/ 专用 Agent / 工作流模板；`llm_adapter` 负责 OpenAI/Ollama/Mock + 熔断降级。

### 6.4 Pin 卡片笔记（Q1-1，详见 Q1 交接文档）
`Annotation.comment` 非空即卡片；`position.cardOrder/color/rects` 承载排序/色条/坐标；点击卡片跳回原文高亮闪烁；写作页一键插入带 `(Author, Year, p. X)` 锚文本。

### 6.5 多文档综述（Q1-2，详见 Q1 交接文档）
`POST /papers/batch/literature-review` SSE：并行 mini 摘要 → 短别名 `\citation{c1,c2}` → 后处理渲染 apa/gb7714/bibtex → 流式 delta + citations 元事件。

## 九、关键设计决策与约定

1. **轻量化零依赖**：SQLite + 内存余弦向量 + 本地 PDF 解析 + LLM 熔断降级 Mock——无 Key 也能全流程演示。
2. **单机单用户**：auto-login 跳过登录页，所有查询按 user_id 过滤，无多租户复杂度。
3. **Pin 卡片零新表**：复用 Annotation 字段承载卡片语义（见 Q1 交接文档）。
4. **综述短别名引用**：`c1/c2` 替代长 UUID 提升模型抄写准确率，后处理还原（见 Q1 交接文档）。
5. **SSE 统一结构**：所有流式接口统一 `data: {delta|citations|done}`，前端 `client.ts` 统一解析，MessageBubble 复用 citation 芯片。
6. **前端 vite.config.js 为生效配置**（非 .ts），已设 `host: '0.0.0.0'`；`.gitignore` 忽略 vite.config.js，改 host 需改 ts 版并重新生成或手动同步。
7. **SQLite 轻量迁移**：新列用 `_migrate_sqlite` 补，不在 SQLAlchemy 层做 Alembic。

## 十一、已知限制与后续路线

1. **演示数据偏少**：库中仅 1 篇 ready 文献，多篇综述演示需先导入更多论文。
2. **LLM 依赖**：未配置时走 Mock（内容占位）；配置后基于真实 chunk 生成。
3. **Windows 打包**：PyInstaller 产物体积大（≈200MB），SQLite 版已做瘦身方案；未在本沙盒验证 Windows 构建。
4. **GB/T 7714 / BibTeX 精确格式**：期刊卷期页码级细节可在 `_review_render_marker` 增强。
5. **跨文献卡片跳转**：会新建 Reader 会话，可加路由缓存做无感返回。
6. **待办建议**：多文档综述的「已选文献→写作插入」可加引用文末列表（References）生成；图谱可联动卡片与综述。

## 十二、交接注意事项

- **不提交**：`researchmate.db`、`storage/`、`node_modules/`、`frontend/dist/`、`.env`、`*.zip` 均在 `.gitignore`；推送前确认无敏感数据。
- **换机器跑**：`pip install -r requirements.txt` + `npm install`；首次启动自动建库建用户。
- **改端口**：设 `PORT` 或改 start 脚本 / vite proxy target。
- **SyntaxWarning "\c"**：papers.py 字符串中的 `\citation` 已写作 `\\citation`，勿改回单反斜杠。
- **浏览器预览**：沙盒内预览需经 `PREVIEW_PROXY_PUBLIC_PORT`（16000）鉴权，IDE 预览面板直接打开即可；浏览器直连 16000 会 401 属正常。
