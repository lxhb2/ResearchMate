ResearchMate 科研助手 · Windows 测试版
======================================

【这是什么】
一款面向科研人员的 AI 学术助手，包含：文献库管理、写作助手、AI 对话、
论文翻译、术语查询等功能。本版本为绿色便携包，无需安装，也不要求电脑
预装任何编程环境。

【如何启动】
1. 把整个文件夹解压到你想要的位置（可放在任意目录，例如 D:\ResearchMate）。
2. 双击 start.bat。
3. 等待几秒，浏览器会自动打开 http://localhost:8000/ 并进入应用。
   （若浏览器未自动打开，请手动访问该地址。）

【如何停止】
双击 stop.bat 即可停止后端服务与数据库。
（也可直接关闭浏览器标签，服务仍会在后台运行。）

【首次使用】
1. 打开应用后，进入「设置」页面。
2. 填写你所用大模型的 API 信息（OpenAI 兼容接口即可，支持国内常见大模型）：
   - 接口地址（Base URL）
   - API Key
   - 模型名称
   填好后点「连接测试」验证，保存即可。
3. 之后即可使用写作、对话、翻译等功能。

【数据保存位置】
你的所有数据（文献、写作项目、设置）都保存在本文件夹的 pgdata 目录中。
请勿删除。如需备份，直接备份整个文件夹即可。

【本测试版说明 / 限制】
- 已禁用 PDF 全文解析（因 GROBID 服务体积过大，正式版会提供）。
  因此「上传 PDF 后自动阅读/解析」功能暂不可用，其余功能正常。
- 端口默认 8000，若被占用请修改 start.bat 中的 PORT 变量。
- 本包为单机单用户设计，数据仅保存在本机。

【常见问题】
- 启动后浏览器打不开：请确认防火墙未拦截，或手动访问 http://localhost:8000/ 。
- 想换端口：打开 start.bat，把 set PORT=8000 改成其他端口，保存后重新运行。
- PostgreSQL 无法启动：查看同目录下 postgres.log 文件。
